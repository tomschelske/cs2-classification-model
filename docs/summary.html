The problem

Given a mid-round game state — players alive and total HP per side, equipment value, utility and defuse kits, bomb planted, time remaining — the model outputs one calibrated probability that the T side wins. It's the same class of model behind win-probability graphics in sports broadcasts: the value isn't just who's likely to win but how confident to be, updated on every kill and the plant.

Pipeline

# HLTV .dem demos
parse.py     windowed demoparser2   → snapshots.parquet (accumulating)
features.py  round + tick data      → labeled snapshots (21 features)
train.py     baseline / logreg / GBM → model.pkl + metrics.json
api.py       FastAPI POST /predict   → calibrated P(T win)
frontend     animated replay        → live win-probability curve

Data & feature engineering

  • Parsed 44 maps across 16 series (BLAST Bounty S2 + IEM Cologne Major 2026; ~14 teams, 8 maps) into 22,706 labeled snapshots — each round sampled every 5 s of live play plus every kill and the bomb plant.
  • Memory-bounded parsing. On an 8 GB machine the high-level parser OOMs on ~450 MB pro demos, so feature extraction requests only the exact ticks it samples (a few hundred per map, not millions) — a whole demo becomes a few thousand rows in ~5 s.
  • 21 features: 7 core (alive / HP per side, bomb, time, round) + 6 secondary (equipment value, utility, defuse kits, score differential) + a map one-hot.

  • Leakage-safe splits. Maps within a Bo3 share the same two teams, so the split is done at the series level (GroupKFold on series id) — no team appears in both training and test.
  • Calibration is the headline. The baseline emits hard 0/1 guesses (log-loss 1.97); the trained model emits probabilities that hold up — when it says 70%, T wins ~70% of the time.
  • The simpler model won, chosen by cross-validation: with mostly monotonic features, logistic regression generalized better than gradient boosting.

Engineering highlights

  • Serving optimization (419×). The deployed model is linear, so the scaler + classifier fold into one weight vector — P = σ(w·x + b) — served from an async handler as a single NumPy dot product instead of a pandas DataFrame per request. Byte-identical predictions; latency 381 µs → 0.9 µs, sustaining 11,709 req/s at 9 ms p99 (0 failures over 20k).
  • Parser reliability. Diagnosed and pinned around a parser regression whose second parse call per process crashed the interpreter, and validated round / event schemas against real data (recording artifacts, warmup filtering).

What the model learned

  • Team economy is the strongest signal — equipment value outranks both bodies and HP. At an even 5v5 full-HP, being on an eco drops win probability to ~9%: equal men with no guns is a near-lost round.
  • A bomb plant is worth ~+20 pp to the T side, men and HP fixed.
  • A man advantage compounds late — a 3v2 (~85%) is a far bigger edge than a 5v4 (~75%).
  • Health matters at equal bodies — a damaged CT side swings ~+27 pp toward T.
